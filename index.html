What this book is

This is a practical guide to databases for Python programmers. It assumes you already know Python fundamentals — variables, functions, loops, files. What it doesn't assume is any prior knowledge of databases, SQL, or how data is stored and retrieved.

You'll go from "what even is a database?" all the way to building real Python programs that store, query, and manage data using both SQLite and PostgreSQL.

Why two databases?

SQLite PostgreSQL ────────────────────────────────────────────────────── Built into Python Separate server Zero setup — just a file Real client-server setup Perfect for local tools Production-ready Great for learning SQL What real apps use sqlite3 (standard library) psycopg2 (pip install) SQL is the same in both — only the connection code changes.

You'll learn SQL once. Then you'll see how to use it with SQLite first (zero setup, great for local tools), then with PostgreSQL (what you'd use in a real application or on a server).

Book structure

Part I — SQL Fundamentals teaches you the language itself. No Python yet — just SQL. By the end you'll be fluent in SELECT, WHERE, JOIN, GROUP BY, INSERT, UPDATE, and DELETE.

Part II — SQLite + Python connects Python to SQLite using the built-in sqlite3 module. You'll build real programs that create databases, store data, and query it back.

Part III — PostgreSQL + Python moves to a real database server. You'll connect with psycopg2 and see what changes — and what stays exactly the same.

Part IV — Projects puts everything together in three complete programs you build from scratch.

🔵 One language, two engines

The SQL you learn in Part I works in both SQLite and PostgreSQL. The only things that change are how you connect and a handful of syntax details. Learn it once, use it everywhere.
