From zero to confidently storing and querying data — with SQLite for local tools and PostgreSQL for real applications.

What this book is

A practical guide to databases for Python programmers. It assumes you know Python fundamentals — variables, functions, loops, files. No prior database knowledge needed.

You'll go from "what even is a database?" all the way to building real Python programs that store, query, and manage data using both SQLite and PostgreSQL.

Why two databases?

SQLite PostgreSQL ────────────────────────────────────────────── Built into Python Separate server Zero setup, just a file Real client-server setup Perfect for local tools Production-ready sqlite3 (standard library) psycopg2 (pip install) SQL is the same in both — only the connection code changes.

Book structure

Part I — SQL Fundamentals — the language itself. SELECT, WHERE, JOIN, GROUP BY, INSERT, UPDATE, DELETE. No Python yet.

Part II — SQLite + Python — connect Python to SQLite using the built-in sqlite3 module. Zero setup required.

Part III — PostgreSQL + Python — move to a real database server with psycopg2.

Part IV — Projects — three complete CLI programs built from scratch.

🔵 One language, two engines

The SQL you learn in Part I works in both SQLite and PostgreSQL. Learn it once, use it everywhere. Only the connection code changes between engines.
