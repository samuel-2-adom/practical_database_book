Sorting & Limiting

Control the order and quantity of results. Two short keywords — ORDER BY and LIMIT — that you'll use in almost every real query.

🎯 What you'll learn
  • Sorting results with ORDER BY
  • Ascending vs descending order
  • Sorting by multiple columns
  • Limiting results with LIMIT
  • Skipping rows with OFFSET (pagination)

5.1 ORDER BY

Without ORDER BY, the database returns rows in no guaranteed order. Use ORDER BY to sort:

SELECT name, age FROM contacts
ORDER BY age;

Default is ascending (smallest first). Add DESC for descending:

SELECT name, age FROM contacts
ORDER BY age DESC;    -- oldest first

SELECT title FROM tasks
ORDER BY title ASC;    -- alphabetical (ASC is default, can omit)

5.2 Sorting by Multiple Columns

Sort by one column first, then break ties with another:

SELECT name, city, age FROM contacts
ORDER BY city ASC, age DESC;
-- sort by city A-Z, then within each city oldest first

5.3 LIMIT

Return only the first N rows:

SELECT * FROM tasks
ORDER BY created_at DESC
LIMIT 5;    -- most recent 5 tasks
💡 Always ORDER BY before LIMIT

LIMIT without ORDER BY returns an arbitrary N rows — whichever the database happens to find first. Always sort first, then limit, to get predictable results like "top 5 newest" or "3 highest priority".

5.4 OFFSET — Pagination

Skip N rows before returning results. Combine with LIMIT for pagination:

-- Page 1: rows 1-10
SELECT * FROM tasks ORDER BY id LIMIT 10 OFFSET 0;

-- Page 2: rows 11-20
SELECT * FROM tasks ORDER BY id LIMIT 10 OFFSET 10;

-- Page 3: rows 21-30
SELECT * FROM tasks ORDER BY id LIMIT 10 OFFSET 20;

Formula: OFFSET = (page_number - 1) * page_size

5.5 Putting It Together

-- Top 3 high-priority pending tasks, most recent first
SELECT title, created_at
FROM tasks
WHERE status = 'pending' AND priority = 'high'
ORDER BY created_at DESC
LIMIT 3;

Notice the order: SELECT → FROM → WHERE → ORDER BY → LIMIT. SQL clauses must appear in this order.

📝 Exercises
Q1 — You want the 5 most expensive products. Which query is correct?
  • A SELECT * FROM products ORDER BY price DESC LIMIT 5;
  • B SELECT * FROM products LIMIT 5 ORDER BY price DESC;
  • C SELECT TOP 5 * FROM products ORDER BY price DESC;
ORDER BY must come before LIMIT in the clause order. TOP is a SQL Server syntax — not used in SQLite or PostgreSQL. Always: ORDER BY first, then LIMIT.
Q2 — Showing 10 results per page. What OFFSET shows page 4?
  • A OFFSET 4
  • B OFFSET 40
  • C OFFSET 30
Formula: (page - 1) × page_size = (4 - 1) × 10 = 30. Skip the first 30 rows to get rows 31-40 (page 4).
🧠 Checkpoint

Write a query that returns the 10 most recently created notes, showing only the title and created_at columns, skipping the first 20 (page 3 of 10-per-page results).

SELECT title, created_at
FROM notes
ORDER BY created_at DESC
LIMIT 10 OFFSET 20;
