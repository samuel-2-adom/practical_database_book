Glossary

Every term used in this book, defined plainly.

Aggregate function
A function that collapses multiple rows into a single value. Examples: COUNT(), SUM(), AVG(), MIN(), MAX().
AUTO INCREMENT / SERIAL
A column property that automatically assigns the next integer value when a new row is inserted. SQLite uses INTEGER PRIMARY KEY; PostgreSQL uses SERIAL.
Column
A named field in a table with a fixed data type. Every row has the same columns.
Commit
Permanently saving a transaction to the database. Changes are not visible to others until committed.
Constraint
A rule enforced on a column or table. Examples: NOT NULL, UNIQUE, PRIMARY KEY, CHECK, FOREIGN KEY.
Cursor
An object that executes SQL statements and retrieves results. Created from a connection object in both sqlite3 and psycopg2.
Database
A program that stores structured data and provides efficient querying, updating, and concurrent access.
DEFAULT
A column constraint that sets an automatic value when no value is provided on INSERT.
DELETE
SQL statement that removes rows from a table. Always use WHERE or you delete everything.
DISTINCT
Keyword that removes duplicate values from SELECT results.
Foreign key
A column that references the primary key of another table, creating a relationship between them.
GROUP BY
Clause that groups rows with the same value in a column so aggregate functions can be applied per group.
HAVING
Clause that filters groups after GROUP BY, like WHERE but for aggregated results.
INSERT
SQL statement that adds new rows to a table.
JOIN
SQL operation that combines rows from two or more tables based on a related column. INNER JOIN returns matches only; LEFT JOIN returns all left rows.
Junction table
A table that resolves a many-to-many relationship by storing pairs of foreign keys. Example: note_tags links notes and tags.
LIKE
Pattern matching operator. % matches any sequence of characters; _ matches one character.
NULL
The absence of a value -- not zero, not empty string. Check with IS NULL, not = NULL.
ORDER BY
Clause that sorts SELECT results. ASC (default) is ascending; DESC is descending.
Parameterised query
A SQL query that uses placeholders (? in sqlite3, %s in psycopg2) for values, preventing SQL injection.
Primary key
A column whose value uniquely identifies each row. Never NULL, never duplicated.
psycopg2
The standard Python library for connecting to PostgreSQL. Install with pip install psycopg2-binary.
Relational database
A database that organises data into tables with rows and columns, and allows tables to be linked.
Rollback
Undoing all changes in the current transaction, returning the database to its previous state.
Row
A single record in a table. One row = one entity (one task, one contact, one note).
SELECT
SQL statement for retrieving data from one or more tables.
SQL
Structured Query Language. The standard language for querying and managing relational databases.
SQL injection
A security vulnerability where malicious SQL is inserted through user input. Prevented by parameterised queries.
sqlite3
Python built-in library for working with SQLite databases. No installation required.
SQLite
A serverless, file-based relational database. Zero setup, single .db file, perfect for local tools.
Table
A collection of related data organised into rows and columns. The core unit of a relational database.
Transaction
A group of SQL statements that either all succeed or all fail together. Guarantees data consistency.
UNIQUE
Column constraint ensuring no two rows have the same value in that column.
UPDATE
SQL statement that modifies existing rows. Always use WHERE or you update every row.
WHERE
Clause that filters which rows are returned or affected by SELECT, UPDATE, or DELETE.
