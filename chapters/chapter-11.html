CRUD with sqlite3

Create, Read, Update, Delete -- all from Python. The SQL from Part I becomes real working code.

What you will learn
  • INSERT from Python
  • SELECT and fetching rows as Python data
  • fetchall, fetchone, row factories
  • UPDATE and DELETE from Python

11.1 INSERT

import sqlite3
from datetime import datetime

def add_task(title, priority="medium"):
    with sqlite3.connect("tasks.db") as conn:
        cur = conn.execute(
            "INSERT INTO tasks (title, priority, created_at) VALUES (?, ?, ?)",
            (title, priority, datetime.now().isoformat())
        )
        return cur.lastrowid

task_id = add_task("Learn sqlite3", "high")
print(f"Created task #{task_id}")

11.2 SELECT

def get_all_tasks():
    with sqlite3.connect("tasks.db") as conn:
        cur = conn.execute("SELECT id, title, status FROM tasks ORDER BY created_at DESC")
        return cur.fetchall()   # list of tuples

for row in get_all_tasks():
    print(f"[{row[0]}] {row[1]} -- {row[2]}")

11.3 Row Factories -- Dicts Instead of Tuples

def get_all_tasks():
    with sqlite3.connect("tasks.db") as conn:
        conn.row_factory = sqlite3.Row
        cur = conn.execute("SELECT id, title, status FROM tasks")
        return [dict(row) for row in cur.fetchall()]

for task in get_all_tasks():
    print(task["title"], task["status"])   # by name, not index

11.4 UPDATE and DELETE

def complete_task(task_id):
    with sqlite3.connect("tasks.db") as conn:
        conn.execute("UPDATE tasks SET status=? WHERE id=?", ("complete", task_id))

def delete_task(task_id):
    with sqlite3.connect("tasks.db") as conn:
        conn.execute("DELETE FROM tasks WHERE id=?", (task_id,))
# note: (task_id,) -- trailing comma makes it a tuple
Single-value tuples need a trailing comma

(task_id) is just parentheses. (task_id,) is a one-element tuple. sqlite3 requires a sequence even for one parameter.

Exercises
Q1 -- fetchone() returns what when no rows match?
  • A Empty list []
  • B None
  • C Raises an exception
fetchone() returns None on no rows. Always check: if row: ...
Q2 -- What does conn.row_factory = sqlite3.Row do?
  • A Makes queries faster
  • B Auto-converts to JSON
  • C Lets you access columns by name instead of index
Row objects support name access. dict(row) converts to a plain Python dict. Far cleaner than row[0], row[1].
