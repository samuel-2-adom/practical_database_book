What Is a Database?

Before writing a single line of SQL, you need to understand what a database actually is — and why files alone aren't enough.

🎯 What you'll learn
  • What a database is and why programs need one
  • How it differs from a plain file or CSV
  • What a relational database is
  • What SQL is and where it fits
  • SQLite vs PostgreSQL at a glance

1.1 Why Not Just Use a File?

Imagine building a contact book stored as a text file. It works for a handful of entries. But what about finding everyone whose name starts with "A", updating one phone number safely, storing 50,000 entries and finding one instantly, or two programs writing at the same time without corrupting each other? A plain file forces you to write all that logic yourself. A database handles it — fast, safely, correctly.

🔵 What a database actually is

A database is a program that stores data in a structured way and lets you query, update, and manage it efficiently. It handles searching, indexing, concurrent access, and corruption prevention — so you don't have to.

1.2 Relational Databases

A relational database stores data in tables — like spreadsheets, but far more powerful. Each table has rows and columns, and tables can be linked to each other.

contacts ┌────┬──────────┬───────────────────┬─────────────┐ │ id │ name │ email │ phone │ ├────┼──────────┼───────────────────┼─────────────┤ │ 1 │ Samuel │ samuel@email.com │ 0244123456 │ │ 2 │ Kwame │ kwame@email.com │ 0201987654 │ │ 3 │ Abena │ abena@email.com │ 0557654321 │ └────┴──────────┴───────────────────┴─────────────┘

1.3 What Is SQL?

SQL — Structured Query Language — is the language for talking to a relational database. It reads like plain English:

SELECT name, email FROM contacts WHERE name LIKE 'A%';

"Give me the name and email of every contact whose name starts with A."

UPDATE contacts SET phone = '0244999888' WHERE id = 1;

"Update the phone for contact 1."

📝 Check Your Understanding
Q1 — Main advantage of a database over a plain text file?
  • A Uses less disk space
  • B Easier to open in a text editor
  • C Handles searching, updating, concurrent access and integrity efficiently
A database isn't just storage — it's a program that manages data intelligently. It finds one row among millions instantly, handles multiple users, and prevents corruption. A text file does none of that without custom code.
Q2 — Building a personal CLI expense tracker. Which database?
  • A SQLite — zero setup, single file, built into Python
  • B PostgreSQL — more powerful
  • C Neither — use CSV
SQLite is perfect for local personal tools. No server, one .db file, sqlite3 already in Python. PostgreSQL's power is overkill for a single-user local tool.
🧠 Checkpoint

In your own words: what is a relational database, what is SQL, and when would you choose SQLite over PostgreSQL?

📌 What to remember

· A database handles searching, updating, and concurrent access for you

· Relational databases store data in tables with rows and columns

· SQL is the universal language for querying relational databases

· SQLite — zero setup, one file, built into Python → local tools

· PostgreSQL — server-based, multi-user → real applications

· SQL is the same in both; only connection code changes
