Part II -- SQLite + Python -- Chapter 10

Intro to sqlite3

Part II starts here. You already know SQL -- now use it from Python. sqlite3 is built in, nothing to install.

What you will learn
  • How sqlite3 connects Python to a database
  • The connection, cursor, execute, commit workflow
  • Creating a table from Python
  • Context managers -- the clean way
SQLite -- no setup needed

sqlite3 is in Python standard library. No pip install, no server. Database is a single .db file created automatically on connect.

10.1 Connecting

import sqlite3

conn   = sqlite3.connect("tasks.db")  # creates file if missing
cursor = conn.cursor()
conn.close()

conn = sqlite3.connect(":memory:")   # in-memory, gone on exit

10.2 Core Workflow

sqlite3.connect("file.db") --> connection conn.cursor() --> cursor cursor.execute("SQL") --> run statement conn.commit() --> save changes cursor.fetchall() --> get SELECT results conn.close() --> clean up

10.3 Creating a Table

import sqlite3

with sqlite3.connect("tasks.db") as conn:
    conn.execute(
        "CREATE TABLE IF NOT EXISTS tasks ("
        "id INTEGER PRIMARY KEY, "
        "title TEXT NOT NULL, "
        "status TEXT NOT NULL DEFAULT 'pending', "
        "priority TEXT NOT NULL DEFAULT 'medium', "
        "created_at TEXT NOT NULL)"
    )
Always use: with sqlite3.connect() as conn

Closes automatically, commits on success, rolls back on error. Use it for everything.

10.4 Complete Setup Function

import sqlite3

DB = "tasks.db"

def init_db():
    with sqlite3.connect(DB) as conn:
        conn.execute(
            "CREATE TABLE IF NOT EXISTS tasks ("
            "id INTEGER PRIMARY KEY, title TEXT NOT NULL, "
            "status TEXT NOT NULL DEFAULT 'pending', "
            "priority TEXT NOT NULL DEFAULT 'medium', "
            "created_at TEXT NOT NULL)"
        )
    print(f"Ready: {DB}")

init_db()
Exercises
Q1 -- What happens when you connect to a .db file that does not exist?
  • A FileNotFoundError is raised
  • B SQLite creates the file automatically
  • C Returns None
SQLite creates the .db file automatically. No manual file creation needed -- just connect and start working.
Q2 -- What is a cursor?
  • A A pointer to one specific row
  • B The database connection itself
  • C An object that executes SQL and retrieves results
cursor.execute() runs SQL and cursor.fetchall() gets results. Separate from the connection object.
